# BoB-Bull-or-Bear---Solana-s-Epic-Prediction-Meme-Coin
🚀 The official Web3 landing page for BoB (Bull or Bear) on Solana. An immersive GameFi meme coin featuring epic 3D scroll-based battles, staking, and market prediction mechanics.

Welcome to the official front-end repository for **BoB (Bull or Bear)**, a revolutionary GameFi meme coin launched on the Solana network via Pump.fun. 

## 🌐 About The Project
BoB is not just a meme coin; it's a dynamic prediction market. The BoB Arena visualizes the eternal struggle of the crypto markets. This web application features premium, Apple-style scroll-based animations that bring the intense clash between the Green Bull and the Fierce Red Bear to life.

In the upcoming BoB Arena Web3 DApp, holders will be able to:
- **Stake to Predict:** Lock $BoB tokens to vote on market sentiment (Bull vs. Bear).
- **Token-Weighted Power:** Your voice matters. Voting power scales with your staked amount.
- **Deflationary Battles:** Losing factions face slashing, with a percentage burned permanently to decrease supply and fuel the buyback ecosystem.

## 🛠 Tech Stack
- **Framework:** HTML5, CSS3, JavaScript / React (Next.js)
- **Animation Engine:** GSAP (GreenSock) & ScrollTrigger
- **Visuals:** High-res Image Sequence for smooth 3D scroll effects
- **Styling:** Tailwind CSS (Cyberpunk/Glassmorphism UI)
